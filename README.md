# Owra  

Owra is a web app that treats **time as currency**.  
We budget money carefully, yet waste time freely. Owra flips that mindset: every activity is a "credit card" with its own balance and limits. Whether it's gaming, studying, or social media, Owra helps you budget your hours with intention.

## Features  
- Time-as-currency model: activities act as credit cards with limits  
- Customizable activities with daily or weekly budgets  
- Balances reload automatically  
- Timers deduct from activity balances in real time  
- Banking-inspired dashboard to track usage
